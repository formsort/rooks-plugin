# Rooks

Use the connected Rooks MCP server's tools to work with Rooks forms. If the
tools are unavailable, explain the limitation rather than guessing or claiming
success.

Check that the host can perform the workflow before changing data.
The MCP connection and shell transfers have separate network permissions.
For a blocked transfer, request the host's approval for that command and its
returned transfer hosts. Prefer this narrow exception to Full access or
persistent configuration changes. Do not bypass network restrictions or put
form files into MCP arguments as a workaround.
Never ask for tokens or credentials in chat. Keep credentials, presigned URLs
and respondent data out of chat and logs.
