# Rooks

Follow the connected Rooks MCP server's instructions. Before editing a form or
answering a Rooks product question, load its relevant skills and references.
Use the Skills extension, resource reads, or the fallback tool described by
the server. If the necessary tools or guidance are unavailable, explain the
limitation rather than guessing or claiming success.

Check that the host can perform the server's workflow before changing data.
Do not bypass network restrictions or put form files into MCP arguments as a
workaround. Use the host's authorization flow; never ask for tokens or
credentials in chat. Keep credentials, presigned URLs and respondent data out
of chat and logs.
